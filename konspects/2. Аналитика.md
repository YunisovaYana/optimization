Виды конкурентов:
- Прямые конкуренты (занимаются тем же, чем и мы: человек, компания, продукт, услуга)
- Косвенные конкуренты (компания, предоставляющая похожие, но идентичные товары или услуги)
- Подменные (предлагают различные услуги, но могут выступать взаимозаменяемыми)

Конкуренция
Смотрим конкурентов: 5 (3 прямые, 2 косвенные) < x < 50

**Матрица позиционирования, карта восприятия**
- Поиск конкурентов
- Популярность (AB) / аудитория (DC) (оси координат, там сравниваем)
- Расчеты

**SWOT-анализ**
Для чего используется SWOT-анализ:
- Анализ точек продаж
- Анализ филиалов
- Анализ направлений продукта
- Анализ направлений бизнеса

S - сильные стороны
W - слабые стороны
O - возможности
T - угрозы

| Внутр факторы / Внеш факторы |                                     O                                      |                                   T                                    |
| :--------------------------: | :------------------------------------------------------------------------: | :--------------------------------------------------------------------: |
|            **S**             |      *Стратегия SO*<br>Реализация возможностей через сильные стороны       | *Стратегия ST*<br>Использование сильных сторон для нейтрализации угроз |
|            **W**             | *Стратегия WO*<br>Использование возможностей для минимизации слабых сторон |    *Стратегия WT*<br>Минимизация рисков на стыке угроз и слабостей     |

| Внутр факторы / Внеш факторы |         Возможности         |       Угрозы       |
| :--------------------------: | :-------------------------: | :----------------: |
|       Сильные стороны        | *Стратегия SO*<br>- рго<br> | *Стратегия ST*<br> |
|        Слабые стороны        |     *Стратегия WO*<br>      | *Стратегия WT*<br> |
