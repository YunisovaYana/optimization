|Ошибка|В чем проблема (простыми словами)|Как исправить|
|---|---|---|
|**Пустые размеры картинок**|У изображений (`<img>`) не указана ширина и высота (`width=""`, `height=""`). Браузер не знает, какого размера должна быть картинка, пока она не загрузится. Из-за этого страница может прыгать|Вписать конкретные числа в пикселях|
|**Повторяющиеся ID**|На одной странице несколько раз встречается одинаковый идентификатор, в HTML ID должен быть уникальным|Заменить повторяющиеся `id` на `class` (классы можно повторять)|
|**Нет описания картинок (alt)**|У некоторых картинок отсутствует атрибут `alt` (текст, который показывается, если картинка не загрузилась, и помогает поисковикам понять, что на ней)|Добавить `alt="описание"` для всех картинок|
|**Тег `<style>` не на своем месте**|Блок с CSS вставлен внутри `<section>` (не по правилам)|Перенести этот блок в `<head>` или в отдельный CSS-файл|
|**Сломанная структура тегов**|Есть незакрытые теги `<div>` и лишние закрывающие `</section>`|Проверить код, найти открытые теги и закрыть их в правильном порядке|
|**Неправильный формат времени**|В теге `<time>` написано «30 минут», но браузер не понимает такой формат|Использовать специальный атрибут `datetime`, например: `<time datetime="PT30M">30 минут</time>`|
|**Нестандартные атрибуты**|Используются атрибуты, которых нет в правилах HTML (например, `swiper-id`)|Заменить на `data-swiper-id`, атрибуты, начинающиеся с `data-`, разрешены|
|**Пустые заголовки**|В коде есть теги `<h4>` без текста внутри|Либо добавить текст в заголовок, либо удалить пустой тег|
|**Лишний `type` у скриптов**|Для тегов `<script>` указан `type="text/javascript"`, в HTML это не нужно|Удалить атрибут `type`, оставить просто `<script>`|
|**Лишний `role` у формы**|У формы указан `role="form"`, браузеры и так понимают, что это форма|Удалить атрибут `role="form"`|
