**2.4. Реализуйте дополнительные возможности сайта**  
- Переключатель темы «День/Ночь»

Добавляем кнопку на главную страницу:  
```
<button class="theme">Переключить тему</button>
```

Прописываем в стилях противоположные цвета для элементов с классом .dark-theme. Далее в js-файл добавляем:  
```
const ok = document.querySelector('.theme');
ok.addEventListener('click', function() {
    console.log("Я работаю");
    document.body.classList.toggle('dark-theme'); 
})
```

И всё, переключатель на странице работает (можем радоваться).
